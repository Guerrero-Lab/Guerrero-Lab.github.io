# Guerrero Lab — official site

Static website for `https://guerrero-lab.com`, with shared privacy policy, support, and terms pages.

## Publication

1. Create public repository `Guerrero-Lab/Guerrero-Lab.github.io`.
2. Replace all instances of `SUPPORT_EMAIL_HERE` in `privacy/index.html`, `support/index.html`, `terms/index.html` with a working address.
3. Verify the privacy policy against final versions of shipped apps. Update before publishing new GX apps.
4. Upload this repository's files preserving folders. Enable Settings → Pages → Deploy from a branch → main → /(root).
5. Test `https://guerrero-lab.github.io/privacy/`, `/support/`, and `/terms/`.
6. In Pages settings, verify and set custom domain `guerrero-lab.com`; then configure the DNS at your registrar following GitHub's current docs. Test HTTPS.
7. Use `https://guerrero-lab.com/` for website, `/privacy/` for privacy policy, `/support/` for support, `/terms/` for terms.

**Important:** This is a starting draft, not legal advice or a declaration that every application has been audited. Never submit placeholder contact details to Meta.
